Child-Space Interaction Workflow

What This System Does

  • Extracts child-space interaction evidence from video
  • Scrapes and compares public playground datasets
  • Vectorises image and text datasets for analysis
  • Visualises the workflow as charts, fragments, and Blender exports

System Narrative

From observed play behavior to reusable design fragments

This interface is the final delivery view for the project. It combines video-based machine learning, structured web scraping, vectorisation, analysis plots, mock design-rule generation, and Blender-ready export into one client-facing demo.
